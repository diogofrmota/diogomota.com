# New Apps Plan

**App name:** Workouts
**App description:** Plan workouts and track strength training.
**Features:** Create routines; log exercises, sets, reps and weights; use a rest timer; review workout history and personal records.

**App name:** Subscriptions
**App description:** Track recurring payments and upcoming renewals.
**Features:** Save cost, billing cycle and renewal date; show monthly and yearly totals; send renewal reminders; track trials and cancellations.

**App name:** Benfica
**App description:** Plan the days you need to go to the stadium for Benfica home matches.
**Features:** Add or update fixtures with opponent, competition and kickoff; mark attendance plans; view upcoming stadium days in a calendar; track ticket status; set match reminders and export calendar events.
